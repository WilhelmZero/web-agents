# 客户定制黑白 Logo

独立路由：`?tool=custom-monochrome-logo`。没有后端服务或示例体验入口。

## 迁移边界

- `prompts.mjs`、`quality-review.mjs`、`auto-tune.mjs` 保留客户定制黑白 Logo 源项目的提示词、审核结构、阈值和决策规则；通过 `.d.mts` 提供类型化调用边界。
- `processing.mjs` 保留源算法的灰度、边界连通清理、Alpha 权重、三尺度纹理、暗部亮纹、黑场曲线、反相与蛇形 Floyd–Steinberg 顺序和公式。
- `image.ts` / `worker.ts` / `workerClient.ts` 替换 Node/Sharp：浏览器转正和解码、Canvas 高质量重采样、可分离 Gaussian（大半径采用三次盒式近似）、PNG pHYs DPI 元数据。输出黑底和擦除区通过最近邻主体遮罩再次锁定。
- 每次预览有独立 Worker 和 AbortController；350ms 防抖，旧 Worker 终止且旧结果不写回。预览队列最多同时运行两个 Worker，卡片最长边 400px、编辑/放大最长边 1200px，按参数缓存。导出逐张重新计算完整尺寸，不使用预览放大。
- 页面复用全局 OpenAI/GPT 密钥与共享 GPT 地址（`openAiEndpoint.ts`），不再保存或读取旧的工具专用地址，也不混用 Gemini 代理。生成配置在右侧独立滚动栏，雕刻参数在逐图编辑弹窗，输出尺寸在下载弹窗。`images/edits` 只按顺序发送原照和风格参考；`responses` 审核发送原照、同一风格参考和渲染结果。连接测试仅 GET `/models`。
- 不自动重复网络、权限、额度或审核失败请求。停止不丢弃正在返回的付费结果，而是在保存后阻止后续步骤。生成请求与审核请求进入全局控制台，只有实际生图响应增加模型张数。
- `storage.ts` 在版本化 localStorage 中只存允许的非密钥设置，在独立 IndexedDB 中存最新任务（Blob、参数、蒙版、评分）。刷新恢复运行态为中断，不自动重发。

## 静态资源与兼容性

仅 `public/engraving-references/*-reference.jpg` 三张风格参考迁入。隐藏展示不意味着私密：这些资源会随 GitHub Pages 公开分发。

兼容服务必须支持 multipart 图片编辑、Base64 PNG 输出、Responses 结构化视觉审核，以及浏览器跨域访问（CORS 和 Authorization）。HTTP 仅允许 localhost；其他地址必须 HTTPS。不依赖原项目的本机 HTTP 代理。

需要支持 OffscreenCanvas、createImageBitmap、Web Worker、IndexedDB 的现代 Chromium 浏览器；不支持的环境显示错误，不静默输出错误图片。

## 逐张结果与补充生成

每次 AI 返回图以独立结果保存：原始图片、初始及当前参数、实际生成提示词、当次风格参考及审核记录。结果区根据可用宽度显示 1/2/3/5 列；参考图仅在生成配置中展示，不在结果内展示。点击卡片放大，调参按钮打开左右布局弹窗。主内容区上方仅展示原照。

逐图参数与自动运行参数分离：`manualParams` 覆盖后续自动审核更新，审核历史与初始参数保持不变。运行过程中也可以编辑、擦除、裁剪和下载已有结果。归一化 `crop` 作用于原始生成图坐标，蒙版同区域裁切，再执行增强、反相与点阵；`null` 表示重置，不修改原文件。关闭弹窗保留参数与已应用裁剪，未应用裁剪取消。

每个结果的下载以及“下载所选”统一进入输出尺寸弹窗，支持毫米＋DPI或像素宽度/边距，并显示实际尺寸。默认 80mm、800 DPI、0mm（约 2520px）；DPI 常用选项包含 800。输出设置沿用独立 `custom-monochrome-logo:export:v1` 键，数据版本升级为 2，旧默认值一次性迁移，新的显式选择不再迁移。确认时冻结所选原图与参数，单张 PNG、多张 ZIP；部分失败允许下载已成功部分，不重发 AI 请求。已有结果的参数保持不变。

结果区提供“清空历史结果”，二次确认后清空本地生成图片、逐图参数、裁剪、蒙版和审核记录；保留原照、风格参考、配置与全局生成统计。运行期间禁用清空，存储失败保留结果；不会清理其他工具的数据。页面不再提供重复的全局 API 设置/测试入口，统一使用右上角配置按钮。

审核增加具体的 `suggestions` 修改意见，低分重生成时加入提示词。综合评分达到用户目标即停止自动循环（维度问题仍展示供人工检查）。补充提示词按钮只生成一张，不进入自动循环且不覆盖之前结果。内置风格参考可查看，也可上传自定义参考并持久保存。DPI 范围 72–1200，支持常见值和手动输入；预览工具栏可切换原照。

## 验证

`engraving.test.ts`：黑底、透明边缘、擦除、暗发、反相、点阵值域、尺寸、DPI、设置、恢复与自动状态机。

`gallery.test.ts`、`preview.test.ts`、`EngravingGallery.test.tsx`：裁剪坐标、输出比例与限制、下载快照与部分失败、手动覆盖、防抖与过期计算、勾选、追加不串图和逐图弹窗。

`api.test.ts`：原提示词、输入顺序、模型参数、连接测试与不自动重试。

`sharpBaseline.test.ts`：`fixtures/sharp-dark-hair.json` 是用源项目 Sharp 处理合成测试像素得到的离线基线，不含客户照片；断言黑底完全相同，允许模糊实现的微小差异。

`CustomMonochromeLogoComposer.test.tsx`：入口、必填上传、默认参数、无示例入口、独立设置。

人工/浏览器 QA 应区分模拟请求和真实服务；模拟通过不代表特定兼容服务的模型权限、CORS 或成品雕刻质量已验证。
