# 文字与扩展画布

在黑白 Logo 的“调节单张参数”中点击“添加文字”。扩展画布始终为黑色，图片可等比缩放、移动，文字图层可分别调整字体、加粗、字号、颜色、描边、行距和字距。文本框自动适应内容宽高，保留手动换行；拖动右下角等比缩放文字并同步修改字号。多行文字默认居中，不再提供内部对齐控件。

“应用”只更新当前结果的可编辑排版；取消不保存。“清除文字与排版”恢复为未排版的生成图，照片参数不受影响。再次裁剪时，新裁剪内容等比适配已有图片框，文字位置不变。

画布与文字使用设计像素。导出宽度/DPI决定最终输出分辨率，文字会按最终分辨率重新绘制；高度取完整排版画布比例。完整输出最大8192像素/边、2400万像素。预览、导出、雕刻模拟及3D传图共用合成入口。

编辑预览显示彩色，雕刻输出将颜色按亮度转换为灰度，黑白点阵在合成后处理。文字不经过照片的锐化/纹理/反相；扩展黑底不反相。排版仅存于单张结果的 params.layout/manualParams.layout，不参与 AI 生成与审核。该字段为可选的 version:1 数据，旧任务不含该字段时保持原渲染。

40款内置字体位于 public/engraving-fonts，合计约833KiB，拉丁字母、数字及常用标点；每款附带其开源许可证。采用静态400字重，加粗通过 Canvas 字重合成；编辑器和导出 Worker 共用同一绘制路径。字体按需从本站加载。内置字体提供样例、分类和搜索。

本机字体通过用户点击“读取本机字体”后由浏览器授权；不支持或拒绝时，可上传TTF/OTF/WOFF/WOFF2（每个最多10MB）。仅缓存选中的字体，按SHA-256去重并存入独立 IndexedDB engraving-fonts-v1；字体内容不会上传。本机字体的使用许可由用户确认。字体缺失或加载失败会提示并阻止应用/输出，不自动换字体；重新导入相同字体可恢复历史排版。

自动验证：layout.test.ts 覆盖参数合法性、排版尺寸、历史兼容、裁剪保留、自动审核参数合并、换行及描边顺序。浏览器验证使用本机模拟图片，无 AI 请求；检查40款字体、用户字体缓存、拖动/缩放、应用/取消、再次编辑、桌面与390px窄屏、灰度和点阵像素及反相黑底。

2026-09-14 交互更新：弹窗内容挂载后立即绑定非被动滚轮监听，首次打开自动按实际视口适配，无需先点击适应窗口或100%。

右侧按图层选择参数：文字显示在上，图片固定底层；拖动文字图层手柄上下排序，手柄聚焦后也可使用上下方向键排序。数值控件使用滑动条和输入框，输入范围不受滑条区间限制，但仍由参数校验和8192/2400万像素输出限制保护。

TextBlock 增加可选 bold 和 autoSize 布尔字段。旧排版不编辑时保留原换行和对齐方式；选择旧文字进行编辑时，仅当前草稿启用自动文本框，取消不保存。自动框按字体实际测量、字距、描边和手写字体伸出部分计算；预览和 Worker 导出共用算法。应用在尺寸测量与绘制完成后才启用，避免保存过期尺寸。

本次回归包括首次滚轮、独立输入范围、选中图层参数、自动文本框、加粗、缩放字号、拖动排序、应用/取消、再次编辑、390px窄屏以及Worker黑白点阵输出。浏览器使用本地测试图，不触发AI。


画布左侧工具栏提供选择移动、添加文本图层、黑色画笔、白色画笔和橡皮擦。文字内容及颜色、描边颜色、加粗、水平居中图标位于画布下方。画笔与橡皮擦分别记住本次编辑的大小（设计像素），使用滑条和输入框调整。图层列表使用独立边框容器，选中行高亮。

画布上方的撤销保留本次窗口内最近50步；一整笔与一次图片/文字拖动均作为一步。应用将排版与笔迹保存在当前结果，取消丢弃草稿；重新打开可继续画，撤销历史不跨窗口保存。清除文字与排版也会清除该结果的笔迹。

version:1 排版增加可选 strokes 数组，每笔记录 mode（缺省paint，也支持erase）、color（黑/白）、size 和设计坐标 points；旧记录兼容。最多2000笔、合计100000个采样点。橡皮擦只在独立透明笔迹层执行 destination-out，之后合成到照片和文字上，不擦除照片、文字或黑色底。编辑预览与最终渲染共用画笔算法；最终分辨率重新绘制，点阵在合成后生成。画笔不进入AI输入。

生成结果封面与全部生成图片弹窗的图片容器使用透明棋盘格背景，仅影响页面展示，不改变导出图片的黑底或透明度。
