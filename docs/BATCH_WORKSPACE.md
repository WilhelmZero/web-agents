# 黑白 Logo 批次工作台

每次“全部生成”都处理当前上传的全部原照（最多20张），在开始时固定一份共用设置。并行数可在1–20之间调整；本地图像渲染仍独立限流。主体固定自动识别、强纹理、内置人物雕刻参考；默认开启扩图，关闭后记住选择。

每张原照显示一个最高分版本封面。分数来自该生成源图的最佳审核参数快照；手动修改后的图片会注明尚未重新审核。点击封面查看所有生成源图及其编辑、下载、雕刻预览功能。本地调参不会增加生成图片数量。

整批历史保存在浏览器 IndexedDB，包含原照任务引用、结果与共用设置，不保存 API Key。刷新会创建空白批次，页面内切换工具保留当前批次；恢复历史会复制为独立任务，不自动调用 AI。自动持续保存，不依赖关闭页面时才保存。浏览器被强制结束、存储不足时最后尚未完成的写入仍可能丢失，请下载重要结果。

单条删除及清空历史需要确认；Web Locks 保护正在其他标签中使用的批次，仍被其他批次引用的图片不删除。旧版单图历史继续可恢复。历史仅在本浏览器本机可用。

“显示生成过程预览”默认开启，图片编辑请求带 `stream=true` 和 `partial_images=3`。解析 `image_edit.partial_image` 与 `image_edit.completed`；每个请求独立处理，停止时取消读取。中间图只用于当前过程展示，不保存进历史、不下载、不审核、不计为生成完成。仅最终事件或普通 JSON 最终响应可形成结果。流式中断或服务错误不会自动重试；兼容服务不支持时可关闭开关后手动生成。

OpenAI 可能返回少于3张中间图；每张中间图有额外图片输出 Token 费用。参考：[图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)、[编辑流式事件](https://developers.openai.com/api/reference/resources/images/edit-streaming-events)。

验证使用模拟请求，覆盖并行交错完成、流事件分块/重复/中断/停止、最佳评分、历史整批保存/恢复/删除保护、刷新空白和窄屏布局，不触发付费生成。
