# SVG 生图与参考图隔离

SVG 在浏览器转为 PNG 后进入 Worker，文件名仍保留 `.svg`，用于选择生图策略。恢复历史任务也依据原文件名。

- SVG 首轮和补充生成：只发送客户图片，雕刻风格由文字提示描述。
- SVG 扩图：发送扩展画布、未改动原图。
- SVG 持续优化：发送最佳候选生成源图、未改动原图。
- 普通照片沿用编辑底图、人物雕刻参考，以及需要时的原图辅助。
- 审核仍对照客户原图、内置雕刻参考、当前效果图；输入角色与图片顺序一致。

`GenerateInput.styleReference` 默认开启，SVG 任务的统一生成包装函数设为关闭，覆盖自动优化和补充生成。图片角色编号由是否带参考及是否带原图辅助共同计算，不再通过提示词字符串替换决定。

参考图拦截比较整体及去黑边后的结构，并容忍有限的纹理和明暗变化。它能拦截部分重绘、压缩和重新留边结果，但不是语义身份识别；审核仍需检查主体是否正确。最终图通过本地检查后才发出完成预览通知。服务已经返回的图片仍计入生成统计，被拦截的请求最终显示失败且不会自动重试。

请求控制台独立保存真实输入数量，每次最多显示4张输入缩略图、2张输出缩略图，全局各保留最近8张。缩略图被省略时仍保留真实数量并显示说明。

验证不调用真实 AI：模拟检查三种 SVG 请求的附件及编号、首次和补充生成路由；浏览器验证参考图原样、JPEG压缩、调色、黑边变化的拦截，以及客户 SVG 和其他参考照片不会误拦截。
